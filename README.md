# Frontier Motorsports Website

Static multi-page site designed for GitHub Pages.

## Pages
- Home
- Road Karting
- Oval Karting
- Partners
- About
- Events
- Contact

## Launch on GitHub Pages
1. Create a GitHub repository, e.g. `frontier-motorsports`.
2. Upload all files/folders from this project.
3. In **Settings → Pages**, select the `main` branch and `/ (root)`.
4. Save. GitHub will provide the live Pages URL.

## Before launch
- Replace the placeholder contact email in `pages/contact.html`.
- Replace placeholder event dates/locations in `pages/events.html`.
- Add real team/driver photography and sponsor logos.
- Add real social links.
- Connect a form service if you want contact submissions without opening email.
